
# 게임 조작 및 코드 리뷰

## 플레이어 행동

| 플레이어가 하는 행동 | 게임에서 일어나는 일 |
| --- | --- |
| A/D 또는 방향키 | 좌우로 이동한다 |
| W/S 또는 방향키 | 전투 공간의 위아래로 이동한다 |
| 마우스 왼쪽 또는 J | 기본 공격을 한다. 이어서 누르면 콤보로 연결된다 |
| 마우스 오른쪽 또는 K | 강공격을 한다 |
| Q | 앞으로 돌진하며 공격한다 |
| E | 적을 띄우는 공격을 한다 |
| Space | 회피한다 |
| F | 가방을 열거나 닫는다 |
| 가방을 연 뒤 1/2/3 | 보유한 주먹·카타나·총 중 하나를 선택한다 |
| 카타나·총을 들고 R | 게이지가 가득 찼으면 궁극기를 쓴다 |
| 주먹을 들고 피해를 받음 | 실제로 줄어든 체력에 따라 분노가 쌓인다 |
| 카타나·총으로 적에게 피해를 줌 | 해당 무기의 궁극기 게이지가 쌓인다 |
| 체력이 0이 됨 | 캐릭터가 기절한다 |

## 리뷰에서 나온 수정해야되는것

| 항목 | 현재 상태 | 다음 조치 |
| --- | --- | --- |
| 체력 UI | 최대 체력을 `/ 100`으로 고정 표시 | `HealthController.Maximum`을 표시하도록 수정 |
| 주먹 분노 | 칼·총을 든 동안에도 저장된 분노가 감소 | 무기를 바꾼 동안 분노를 보관할지 결정한 뒤 수정 |
