# 처음 하는 사람을 위한 게임 설명서

카드·다트·단검을 다트판에 던져 **목표 점수를 넘기는 게임**입니다. 카드는 같은 숫자나 문양을 모으면 ‘족보’가 되어 점수가 배로 늘어납니다. 전투가 끝나면 칩을 정리하고 도구를 준비해 다음 전투로 갑니다.

## 1. 이렇게 한 판 하세요

1. **도구 준비:** 발판 옆 카드 테이블에 놓인 도구가 이번 전투의 도구입니다. 비어 있다면 왼쪽 벽 슬롯머신 옆 **공짜 다트 바구니**를 좌클릭해 다트를 집고, 카드 테이블을 보고 좌클릭해 놓으세요.
2. **전투 시작:** 손에 다른 물건이 있으면 내려놓고, 바닥의 **THROW 발판 위에서 다트판 중앙을 바라보세요.** 자동으로 투척 자세가 됩니다.
3. **던지기:** 화면 아래 카드나 다트를 **좌클릭한 채 들어 올려 손패 밖으로 옮긴 뒤, 마우스를 휘두르는 도중 버튼을 놓으세요.** 오래 누르기만 하면 힘이 생기는 방식이 아닙니다.
4. **결과 확인:** 준비한 도구를 모두 던지고 착지하면 점수를 계산합니다. 목표에 도달했어도 남은 도구를 모두 던져야 합니다.
5. **다음 전투 준비:** 클리어하면 결과 화면의 칩 줍기 버튼으로 방에 돌아옵니다. 칩과 사용한 도구를 회수하고, 카드 테이블에 다음 도구를 놓은 뒤 다시 THROW 발판으로 가세요.

전투는 **일반전 → 보스전 → 상점** 순서로 반복되며 총 30스테이지입니다. 보스 뒤 상점은 방 안 매대로 이용하므로 다음 전투의 스테이지 번호가 하나 건너뛸 수 있습니다.

## 2. 필요한 조작

| 행동 | 방을 걸을 때 | 전투할 때 |
|---|---|---|
| 마우스 이동 | 주변 둘러보기 | 들고 있는 도구 움직이기 |
| 좌클릭 | 가까이서 바라보는 물건 줍기·놓기·투입·구매 | 카드·다트를 누른 채 들고, 휘두르며 놓아 투척 |
| 우클릭 | 빈 방향을 보고 손의 물건 던지기. 칩·현금은 가까운 빈 바닥에 내려놓기 가능 | 단검이 있으면 누른 채 준비하고 휘두르며 놓아 투척 |
| `W / A / S / D` | 앞 / 왼쪽 / 뒤 / 오른쪽 이동 | `S`는 카드 문양순 정렬 |
| 왼쪽 `Shift` / `Ctrl` | 달리기 / 누르는 동안 앉기 | — |
| `Space` + 좌클릭 | 쌓인 칩·지폐를 더미나 묶음으로 집기 | — |
| `Q` / `N` | — | 도구 내려놓기 / 카드 숫자순 정렬 |
| `Esc` | 일시정지·계속하기 | 일시정지·감도와 확대율 설정 |
| `P` | 현금으로 사는 편의성 상점 목록 | — |

카드는 화면 아래 손패 안에서 놓으면 던져지지 않고 순서만 바뀝니다. 단검을 준비하지 않는 상태의 우클릭 드래그는 카드 각도를 조절하며, **휠 버튼 클릭으로 각도를 초기화**합니다. `R`은 상태에 따라 재시작·정산·재도전으로 작동하므로 처음에는 결과 화면의 버튼을 사용하세요.

## 3. 점수는 ‘명중 점수 × 카드 족보’

**강화가 없을 때: 최종 점수 = 명중으로 쌓은 점수 합계 × 가장 높은 족보의 배율**

- **카드 명중:** 맞힌 구역 점수 + 카드 숫자 점수. 숫자 카드는 적힌 값, J·Q·K는 10, A는 11입니다.
- **다트·단검 명중:** 맞힌 구역 점수만 더합니다. 자체적으로 카드 족보를 만들지는 않습니다.
- **빗나감:** 0점이며 그 카드도 족보에 들어가지 않습니다. 족보가 없으면 배율은 ×1입니다.

### 다트판 점수

| 맞힌 곳 | 점수 |
|---|---|
| 넓은 싱글 구역 | 적힌 숫자 그대로. 싱글 20은 20점 |
| 가장 바깥쪽의 좁은 더블 띠 | 숫자 ×2. 더블 20은 40점 |
| 안쪽의 좁은 트리플 띠 | 숫자 ×3. 트리플 20은 60점 |
| 중앙 주변 / 정중앙 | 25점 / 50점 |
| 판 밖 | 0점 |

결과의 `S / D / T`는 싱글 / 더블 / 트리플입니다. 처음에는 좁은 고득점 띠보다 넓은 구역에 확실히 꽂으세요. 바람 때문에 궤적이 달라질 수 있습니다.

### 카드 족보

족보는 명중한 카드에서 가장 높은 것 하나를 적용합니다. 문양은 ♠·♥·♦·♣ 네 종류이며, 같은 색이어도 문양이 다르면 서로 다릅니다.

| 족보 | 필요한 카드 | 기본 배율 |
|---|---|---|
| 원 페어 | 같은 숫자 2장 | ×2 |
| 투 페어 | 서로 다른 숫자의 페어 2쌍 | ×2 |
| 트리플 | 같은 숫자 3장 | ×3 |
| 스트레이트 | 연속 숫자 5종. 예: 5·6·7·8·9 | ×4 |
| 플러시 | 같은 문양 5장 | ×4 |
| 풀 하우스 | 같은 숫자 3장 + 다른 숫자 2장 | ×4 |
| 포카드 | 같은 숫자 4장 | ×7 |
| 스트레이트 플러시 | 같은 문양으로 연속 숫자 5장 | ×8 |
| 로열 플러시 | 같은 문양의 10·J·Q·K·A | ×8 |

A·2·3·4·5도 스트레이트입니다. **처음에는 같은 숫자 두 장으로 원 페어를 노리세요.** 예를 들어 8 카드 두 장을 각각 싱글 20에 꽂으면 `(20+8 + 20+8) ×2 = 112점`입니다. 강화와 보스의 공용 카드가 없는 예시입니다.

**보스전:** 처음부터 판에 있는 공용 카드도 내 족보에 포함됩니다. 보스와 동점이면 패배하므로 화면의 **‘N점 이상’**까지 올리세요. 보스 화면은 공용 카드만의 기본 점수를 내 점수와 목표에서 함께 빼서 보여줍니다. 20스테이지부터는 목표 숫자가 숨겨지지만 승패 판정은 유지됩니다.

## 4. 칩과 현금은 용도가 달라요

**실물 칩은 도구·강화 구매와 패배 정산에, 현금($)은 편의성 도구 구매에 씁니다.** 칩마다 액면가가 다르므로 개수보다 총가치를 보세요. 점수 계산에 나오는 ‘칩’은 전투 점수의 재료이고, 물건을 사는 돈은 방에서 회수하는 실물 칩입니다.

| 할 일 | 어디서·어떻게 |
|---|---|
| 칩 줍기·보관 | 바닥 칩을 가까이서 좌클릭. 오른쪽 칩 테이블에 좌클릭해 놓기 |
| 새 도구 얻기 | 왼쪽 벽 슬롯머신에 **손에 직접 든 칩 가치 3**을 좌클릭으로 투입. 무작위 보상을 경품함에서 집어 카드 테이블에 놓기. 매번 도구가 나오지는 않음 |
| 도구 재사용·반환 | 전투 후 사용한 도구를 좌클릭으로 회수. 멀쩡하면 카드 테이블에 놓고, 파괴되었으면 다트판 왼쪽 반환기에 투입. 다트 1·카드 3·단검 5의 칩 가치 반환 |
| 카드 강화 구매 | 보스 클리어 후 방 안 카드 상점에서 상품을 좌클릭해 보유 칩으로 구매 |
| 현금 만들기 | 칩을 들고 ATM에 좌클릭해 투입. **칩 가치 1 = $1. 배출구 지폐까지 직접 집어야 수령 완료** |
| 현금 보관·꺼내기 | 오른쪽 테이블 현금 구역의 빈 트레이를 클릭해 보관. 지폐 더미를 클릭해 다시 꺼내기 |
| 편의성 도구 구매 | 뒷벽 매대 또는 `P` 목록에서 현금으로 구매 |

슬롯은 좌클릭을 누르고 있으면 칩이 있는 동안 다음 회전도 이어집니다. 한 번만 돌리려면 버튼을 놓으세요. 바닥 물건은 쥐에게 도난당할 수 있으니 회수하고, 다음 전투의 여유가 되도록 칩을 남겨 두세요.

**강화 효과:** 행성은 지정 족보 배율 +1, 구역 각인은 해당 숫자 구역에 명중한 카드의 칩 배율 +1입니다. 타로는 사용한 전투의 최종 칩 ×2, 부적은 사용한 전투의 족보 배율 +2입니다. 타로는 1회용, 부적은 구매당 3회이며 전투 화면의 사용 버튼으로 적용합니다.

## 5. 실패해도 칩이 남으면 재도전

1. **재추첨:** 결과 화면에 ‘빗나간 카드 다시 뽑기’ 버튼이 있으면 새 카드로 이어서 도전할 수 있습니다. 전투당 최대 2회이며 빗나간 카드와 남은 덱이 있어야 합니다.
2. **패배 정산:** 일반전은 그 전투에서 발생한 칩 가치만큼을 회수합니다. 보스전은 카드 선택을 거쳐 정하며, 선택 카드 숫자와 던진 다트·단검 수가 클수록 회수 배율이 커집니다.
3. **재도전:** 정산 후 칩이 남으면 같은 스테이지에 다시 도전합니다. **칩 가치가 0이면 게임 오버**이며 처음부터 시작합니다.

## 6. 막히면 이것만 확인하세요

- **전투가 시작되지 않음:** 테이블에 도구를 놓고 손을 비운 뒤, THROW 발판에서 판 중앙을 보세요.
- **도구가 던져지지 않거나 안 꽂힘:** 손패 밖에서 마우스를 휘두르며 놓으세요. 카드 각도는 휠 버튼으로 초기화하고, 감도가 맞지 않으면 Esc에서 조절하세요.
- **물건을 못 주움:** 가까이 다가가세요. 손이 가득 찼거나 다른 종류의 물건을 들었다면 먼저 내려놓으세요. 가구 밑은 Ctrl로 앉아 확인하세요.
- **슬롯이 안 돌아감:** 현금이나 테이블의 칩으로는 안 됩니다. 칩 가치 3 이상을 직접 손에 드세요.

단검이 생기면 우클릭으로 준비해 보세요. 슬로모션 중 날아가는 카드를 베면 **기본 40점 + 카드 숫자 점수**를 얻습니다. 일반 투척이 익숙해진 뒤 시도하면 됩니다.
